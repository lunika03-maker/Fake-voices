# Fake-voices

Claro, siguiendo el mismo estilo y nivel de detalle:

En este proyecto desarrollamos una aplicación de generación de voces mediante inteligencia artificial, cuyo objetivo fue experimentar con la transformación de texto en audio. La aplicación permite introducir un texto para posteriormente procesarlo mediante una herramienta de IA capaz de generar una voz artificial a partir de la información proporcionada. Durante el ejercicio se trabajó con elementos de interfaz como campos de texto, botones y opciones para facilitar la interacción del usuario y obtener el resultado de manera sencilla. Este proyecto permitió conocer una aplicación práctica de la IA en la generación de contenido audiovisual, así como comprender cómo los datos introducidos por el usuario pueden ser procesados para producir un resultado sonoro. Además, ayudó a explorar las posibilidades de las tecnologías de síntesis de voz y su aplicación dentro del desarrollo de herramientas digitales.
